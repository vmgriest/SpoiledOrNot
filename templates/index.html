🎯 How It Works: Multi-Modal AI

  • CV Model (ResNet-18): Classifies produce freshness in real-time using computer vision
  • Object Detection (Faster R-CNN): Locates produce in the frame for accurate classification
  • Gemma 4 LLM: Provides natural language analysis with storage recommendations and safety assessment
  • Multi-Modal Fusion: CV results feed into the LLM prompt for context-aware AI analysis

The system combines a traditional computer vision pipeline with a large language model to give you both fast classification and detailed, expert-level insights about your produce.
